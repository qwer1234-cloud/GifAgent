# P1b — Tag mapping to the frozen vocabulary (v1)

You are mapping one JSONL input shard onto the frozen canonical tag vocabulary
(`tag_vocab_v1.json`, located at the sprint root; its path is given to you by
the coordinator/executor).

## Input

Each input line is a JSON object with text-only fields (`candidate_id`,
`vlm_summary_json`, `tags_json`, `scenario_keys_json`, `final_score`,
`stratum`).

## Hard rules

1. Process the input line by line, in order. Output exactly one JSON line per
   input line (JSONL, UTF-8, no markdown fences).
2. Read text fields only. NEVER open, view, or read any GIF, JPG, PNG, video,
   or other media file.
3. Do NOT sanitize, soften, or euphemize adult sexual semantics: if a clip is
   explicit, choose the explicit tags that describe it. Sanitized output will
   be flagged and counted as a failure.
4. If you cannot produce tags for a row, output the refusal line
   `{"candidate_id": "<id>", "refused": true}` instead of guessing.
5. Never invent `candidate_id` values; copy them exactly from the input.

## Task

For each input row, choose the tags from the frozen vocabulary that describe
the clip's content.

## Output schema (per line)

```json
{"candidate_id": "<id>", "tags": ["<tag>", ...]}
```

- `tags` MUST be a JSON array of strings, each EXACTLY equal to an entry of
  `tag_vocab_v1.json`. Tags outside the vocabulary are schema failures.
- Prefer 2 to 10 specific tags per row; an empty array is allowed only when
  nothing in the vocabulary applies.
- No duplicates within one row.
