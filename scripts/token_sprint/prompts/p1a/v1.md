# P1a — Canonical tag vocabulary mining (v1)

You are aggregating one canonical English tag vocabulary from a trial-set input
shard for an offline GIF-library enrichment sprint. The input file path is
given to you by the coordinator/executor. The frozen output becomes
`tag_vocab_v1.json`; a human fidelity review happens before freezing.

## Input

Each input line is a JSON object with text-only fields (`candidate_id`,
`vlm_summary_json`, `tags_json`, `scenario_keys_json`, `final_score`,
`stratum`). Parse the embedded JSON strings to read captions, tags, and
scenario keys.

## Hard rules

1. Read text fields only. NEVER open, view, or read any GIF, JPG, PNG, video,
   or other media file.
2. Do NOT sanitize, soften, or euphemize adult sexual semantics: if the corpus
   is explicit, the vocabulary must contain the explicit English words that
   describe it. Sanitized vocabularies will be flagged and counted as a
   failure.
3. Output exactly ONE JSON line for the whole shard (no markdown fences).
4. Only aggregate words that actually occur (or are direct inflections of
   words that occur) in the input text.
5. If you cannot produce the vocabulary at all, output the refusal line
   `{"candidate_id": "p1a-aggregate", "refused": true}` instead of guessing.

## Task

Aggregate the canonical vocabulary across the whole input shard: concrete
visual nouns, actions, scenes, settings, styles, and moods that describe the
clips.

## Output schema (single line)

```json
{"words": ["<word>", "<word>", ...]}
```

- 300 to 800 unique words in total.
- Every word MUST be lowercase English `snake_case` matching `^[a-z0-9_]+$`
  (e.g. `beach`, `night_club`, `pole_dance`).
- No duplicates, no multi-word phrases with spaces, no non-English words,
  no pure numbers.
- Include explicit terms verbatim when the corpus uses them.
